## 작업 요약
파트너 대시보드에서 고객 자료 수집 단계를 건너뛰고 PR 홈페이지를 바로 제작할 수 있는 기능 추가.
기존 "PR 홈페이지 제작" 빠른 작업 버튼이 방송인 목록 페이지로만 이동하던 문제를 해결하고,
신규 `/app/build` 페이지에서 고객 선택/등록 + 프로젝트 생성 + 빌더 진입을 한 흐름으로 처리.

## 변경 사항

### 추가된 기능
- **직접 제작 페이지** (`/app/build`): 2단계 위저드
  - Step 1: 기존 고객 검색·선택 OR 신규 고객 인라인 등록 (이름·영문명·포지션)
  - Step 2: 프로젝트명 자동 제안 + 직접 제작 모드 안내 → 빌더로 이동
- **Quick API** (`/api/build/quick`): 고객 생성(필요시) + 프로젝트 생성을 원자적 처리
  - `intakeMode: OPERATOR_ENTRY`, `status: DRAFTING` 으로 자료 수집 단계 건너뜀
  - Audit 로그 + Timeline 이벤트 기록

### 수정된 사항
- `src/app/app/layout.tsx`: 사이드바 nav에서 "PR 빌더는 고객 상세에서 진입(info)" 항목을 "직접 제작" 실제 링크(`/app/build`)로 교체
- `src/app/app/page.tsx`: 대시보드 빠른 작업 "PR 홈페이지 제작" 버튼 href를 `/app/talents` → `/app/build`로 수정

### 삭제/제거된 사항
