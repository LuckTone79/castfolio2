## 작업 요약
파트너 랜딩(`/`) 헤더의 **"고객 전용 페이지" 버튼이 모바일에서 숨겨져** 있어, 고객용 사이트(`/client`)로 들어가는 진입점이 모바일 사용자에게 보이지 않던 문제를 수정했다.

## 진단
- 사용자가 "고객용(방송인용) 사이트와 진입 버튼이 사라졌다"고 보고했으나, 조사 결과 **`/client` 랜딩 페이지와 헤더 버튼은 코드상 그대로 존재**했다(v3.0.0/v3.1.0에서 삭제된 적 없음).
- 실제 원인: v2.1.0에서 추가된 "고객 전용 페이지" 버튼의 클래스가 `hidden ... sm:inline-flex`라 **모바일(sm 미만)에서 비표시**였다. 모바일에서 접속한 사용자에게는 진입 버튼이 보이지 않았다.

## 변경 사항
- `src/app/page.tsx` 헤더의 "고객 전용 페이지" 버튼을 **모든 화면에서 노출**되도록 변경(`hidden`/`sm:inline-flex` 제거 → 항상 `inline-flex`).
- 모바일에서 "파트너로 시작하기"와 나란히 놓여도 넘치지 않도록 두 버튼 모두 **모바일 패딩·글자 크기 축소**(`px-3 py-2 text-xs` → `sm:`에서 원래 크기 복원).
- `/client` 고객용 랜딩 페이지 자체는 정상이므로 변경하지 않음(확인만 수행).
