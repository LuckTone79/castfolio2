## 작업 요약
v3.0.0에서 **사이드바 IA(정보구조)는 워크플로우 기반으로 재설계**했으나, **홈 화면과 세부 진입 동선은 기존 그대로**여서 최적화된 구조를 체감하기 어렵다는 문제를 개선했다.
홈을 **"워크플로우 액션 센터"**로 재설계하고, 세부 메뉴 간 컨텍스트 연결을 보강했다.
**제작 결과물(PR 홈페이지) 디자인은 이번에도 전혀 변경하지 않았다.**

### 발견한 핵심 문제
1. **홈이 워크플로우를 반영하지 못함**: 통계카드 + 빠른작업 + 최근목록의 범용 대시보드 구조라, 이 프로그램의 본질인 `신규 → 자료수집 → 제작 → 검수 → 납품 → 정산` 파이프라인이 보이지 않고 "지금 무엇을 해야 하는지" 안내가 없었다.
2. **세부 메뉴 단절**: 방송인 고객 상세에서 "PR 홈페이지 제작"을 눌러도 빈 빌드 화면이 떠 고객을 **다시 검색·선택**해야 했다(컨텍스트 유실).
3. 파이프라인 단계별 프로젝트를 바로 볼 수 있는 **딥링크 진입점 부재**.

## 변경 사항

### 홈 재설계 — 워크플로우 액션 센터(`/app`)
- **KPI 스트립**: 이번 달 판매금액 · 예상 정산금 · 진행 중 프로젝트 수 · 공개된 PR 홈페이지 수.
- **제작 파이프라인 보드**(신규 클릭형): `신규 · 자료수집 · 제작중 · 검수중 · 납품준비 · 납품완료` 6단계를 단계별 실시간 건수와 함께 시각화. 각 단계 클릭 시 해당 상태로 필터된 프로젝트 목록(`/app/projects?status=...`)으로 이동.
- **"지금 할 일" 액션 센터**: 파트너 액션이 필요한 항목만 데이터 기반으로 노출(납품 준비 완료 · 고객 검토 중 · 제작 진행 중 · 자료 수집 중 · 판매·정산 대기). 각 카드에 직접 CTA. 처리할 일이 없으면 긍정 상태 표시.
- **최근 활동**: 최근 등록 고객 · 최근 공개 PR 홈페이지(각 섹션에 "전체보기" 추가).
- 상단에 주 CTA "PR 홈페이지 제작" 버튼 배치(read-only 계정은 숨김).

### 세부 메뉴 컨텍스트 연결
- 방송인 고객 상세 → "PR 홈페이지 제작" 링크에 `?talentId=` 전달.
- 빌드 플로우(`/app/build`)가 `talentId` 쿼리를 받아 **해당 고객을 자동 선택**한 상태로 시작(재검색 불필요).

### 딥링크 지원
- 프로젝트 목록(`/app/projects`)이 `?status=` 쿼리를 읽어 **상태 필터가 적용된 상태로 진입**(파이프라인 보드 연동). `useSearchParams` 사용에 따라 `Suspense` 경계로 감쌈.

### 유지(미변경) — 결과물 디자인
- PR 페이지 렌더러, Type1/Type2 레이아웃, 테마 시스템(2×10=20), 공개 페이지 `/p/[slug]`는 **전혀 변경하지 않음**.

## 알려진 이슈 / 추후 작업
- "지금 할 일" 항목은 상태별 집계(건수) 기반이며, 향후 개별 프로젝트 단위 알림/마감일 표시로 확장 가능.
- 빌드 게이트(`next build`)는 DB 환경변수 필요로 본 작업 범위에서 미실행(타입체크로 대체 검증).
